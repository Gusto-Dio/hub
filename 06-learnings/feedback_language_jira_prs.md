All Jira comments, PR titles, and PR bodies must be written in English — never in Portuguese.

**Why:** Jira and GitHub are shared with the whole team (including non-Portuguese speakers). Portuguese in those channels is a communication gap.

**How to apply:** Before posting any Jira comment or creating any PR, confirm the content is fully in English. Conversation with the user stays in Portuguese/English mix as usual — only the external artifacts (Jira, GitHub) must be English.
